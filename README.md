### About

I build and ship production web applications end to end, from schema design to deployment. I founded [GrayVally Software Solutions](https://www.grayvally.tech) in Dhaka and lead the Software Lab at [ZTEC Group Pty Ltd](https://ztecgroup.com.au) in Perth, Australia.

Most of my work is client production code, so a lot of it lives in private repos. The public repos here are tools, experiments, and the projects I own outright.

### What I actually do on a project

- **Scoping and architecture.** Written scope, fixed price, delivery date before any code.
- **Backend.** REST and typed APIs, relational schema design, auth, background jobs, migrations.
- **Frontend.** Next.js App Router, component systems, scroll-driven animation, Core Web Vitals.
- **Infrastructure.** Docker on DigitalOcean, Vercel, Netlify, Supabase, CI, domains, DNS, email deliverability.
- **Growth plumbing.** Technical SEO, Meta Pixel and Conversions API with event deduplication, analytics.
